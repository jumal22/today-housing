개인정보처리방침

시행일: 2026년 10월 12일

1. 수집하는 항목

  • 가입할 때(필수): 이메일 주소, 닉네임, 비밀번호(이메일로 가입하는 경우)
  • Google로 가입·로그인할 때: Google이 제공하는 이메일 주소와 이름(프로필 정보). 비밀번호는 받지 않습니다.
  • 서비스를 이용하면서 생기는 정보: 게시물(제목, 가구 배치 데이터, 썸네일, 선택한 경우 도면·벽 이미지), 댓글, 좋아요, 로그인 시각 등 접속 기록
  • 가입 없이(비회원으로) 글·의견·하트를 남길 때: 입력한 닉네임과 접속 IP 주소. 화면에는 IP 앞 두 자리만 닉네임 옆에 표시되고, 전체 IP는 도배·중복 하트 방지에만 쓰이도록 암호화(해시)해서 저장합니다.

2. 수집·이용 목적

  • 회원 식별과 로그인, 인증 메일·비밀번호 재설정 메일 발송
  • 갤러리 게시, 댓글, 좋아요 등 서비스 기능 제공(닉네임이 다른 이용자에게 표시됩니다)
  • 부정 이용 방지(도배 쿨타임, 같은 IP의 중복 하트 제한), 문의 대응, 서비스 개선
  • 회원 관리: 운영자(관리자)는 회원 관리를 위해 이메일 주소와 닉네임을 열람하고 회원 구분(일반 회원·인테리어 업자·관리자)을 지정할 수 있습니다.

3. 보유·이용 기간

회원 탈퇴 시까지 보관하며, 탈퇴하면 지체 없이 삭제합니다. 법령에 따라 보관해야 하는 정보는 그 기간 동안만 따로 보관합니다. 이용자가 직접 삭제한 게시물과 댓글은 바로 삭제됩니다. 도배 방지용 IP 기록은 1일 뒤 지워지고, 중복 하트 확인용 기록은 하트를 취소하거나 게시물이 삭제될 때 지워집니다.

4. 저장·처리를 맡기는 곳

서비스 운영을 위해 다음 외부 서비스를 이용하며, 이 과정에서 정보가 국외 서버에 저장될 수 있습니다.

  • Supabase: 회원 인증, 데이터베이스, 이미지 파일 저장
  • Vercel: 웹사이트 호스팅
  • Google: Google 계정으로 로그인하는 경우의 인증

Google 로그인으로 받은 정보(이메일 주소, 이름)는 로그인과 계정 식별에만 쓰며, 광고나 제3자 제공에는 쓰지 않습니다. 오늘의 하우징의 Google API 정보 이용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 비밀번호 보호

비밀번호는 암호화(해시)되어 저장되며, 운영자도 원래 비밀번호를 볼 수 없습니다.

6. 동의를 거부할 권리

개인정보 수집·이용에 동의하지 않을 수 있습니다. 다만 동의하지 않으면 회원가입과 게시, 댓글 기능을 이용할 수 없습니다. 둘러보기는 가입 없이 가능합니다.

7. 이용자의 권리

이용자는 언제든지 자신의 정보를 열람·정정·삭제하거나 탈퇴를 요청할 수 있습니다.
